# public-delivery Specification

## Purpose
Support the Garden Chat social experience through public delivery with verifiable visitor behavior.

## Requirements

### Requirement: Published experience
The public repository and GitHub Pages build SHALL provide working multiplayer movement and chat, correct subpath assets, displayed release version and setup documentation.

#### Scenario: Open public release
- **WHEN** a visitor opens the released URL in a WebGPU browser
- **THEN** the garden assets load and multiplayer connects without runtime errors
